실패 시 진행 토스트를 종료하고 팝업 하나만 엽니다. 자동으로 닫지 않으며 같은 실패 토스트를 중복 표시하지 않습니다. ‘다시 시도’는 팝업을 닫고 같은 작성 내용·첨부 파일로 재전송하며 진행 상태를 표시합니다. 전송 중 중복 요청을 막고, 성공하면 등록 완료 안내, 재실패하면 같은 팝업을 표시합니다.

‘취소’는 재시도를 하지 않고 팝업을 닫습니다. 작성 내용·첨부 파일의 보존과 팝업을 닫은 뒤 다시 시도할 경로는 개발 확인 항목입니다. 보존이 검증되지 않은 상태에서 저장 완료를 안내하지 않습니다.

등록 실패 팝업은 별도 확인창으로 화면 중앙에 표시합니다. 토스트는 항상 상단에 표시합니다. 원인이 확인된 용량 제한·파일 형식 등의 별도 오류가 있다면 구체적인 해결 안내를 유지합니다.

팝업 내 재전송은 가능한 동작으로 확인되어 적용합니다. ‘취소’를 누른 뒤에도 데이터를 보존하는지는 별도 확인 항목이며, 팝업을 열어 둔 상태의 재전송과 구분합니다.

조건에 맞는 항목이 없습니다. 검색어나 필터를 바꿔 주세요.

‘유지’는 문구와 아이콘 기준입니다. 공통 디자인·마침표 규칙은 유지 행에도 적용합니다. AS-IS의 ‘미대조’에는 ‘확인 필요’ 태그를 중복 표시하지 않습니다. 미확인 항목은 ‘확인 필요’ 필터에서 계속 볼 수 있습니다. 수정할 내용과 미확인 내용이 함께 있으면 두 필터에 모두 나타납니다.
